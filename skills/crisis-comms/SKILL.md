# Crisis Communications & Paid Media Emergency Protocol

When a brand crisis strikes—a product defect, executive scandal, viral boycott, or regulatory inquiry—the worst thing an agency can do is keep running happy, upbeat ad campaigns. Pumping ad spend into a trending crisis wastes thousands of dollars providing an open billboard for enraged commenters, permanently damaging brand equity.

This skill provides an emergency operating playbook: executing an immediate 15-minute paid media killswitch, triaging crisis severity, drafting calibrated holding statements, and managing stakeholder sequencing.

---

## 2. The 15-Minute Paid Media Killswitch

```
+-------------------------------------------------------------------------------+
|                       15-MINUTE EMERGENCY KILLSWITCH                          |
+-------------------------------------------------------------------------------+
|  MINUTE 0 - 5: THE PAUSE SPRINT                                               |
|  - Meta Ads: Toggle Account-Level Campaign status to PAUSED                   |
|  - Google Ads: Pause YouTube & Display campaigns (keep Brand Search active    |
|    ONLY IF directing to crisis FAQ)                                           |
|  - TikTok & LinkedIn Ads: Immediately pause all active flights                |
|                                                                               |
|  MINUTE 5 - 10: AUTOMATED MARKETING HALT                                      |
|  - Klaviyo / ESP: Abort scheduled email campaigns & promotional SMS broadcasts |
|  - Organic Social: Turn off scheduled Hootsuite/Buffer/Sprout posts           |
|                                                                               |
|  MINUTE 10 - 15: AD COMMENT LOCKDOWN                                          |
|  - Enable keyword moderation filters on Meta & TikTok pages                   |
|  - Add crisis keywords to blocklist to prevent toxic ad comment cascading     |
+-------------------------------------------------------------------------------+
```

## 3. The 3-Tier Severity Escalation Ladder

```
+-------------------------------------------------------------------------------+
|  TIER 1: LOCALIZED / CONTAINED (Low Risk)                                     |
|  - Definition: Isolated negative comment thread, single unhappy influencer    |
|  - Media Action: Keep ads running; handle via customer support DM             |
|  - Stakeholders: Community Manager + Media Buyer                              |
+-------------------------------------------------------------------------------+
|  TIER 2: ESCALATING / CHANNEL-WIDE (Moderate Risk)                            |
|  - Definition: Customer complaints spike >300%, micro-influencer callout,    |
|    localized stock outage or shipping delay impacting >500 customers          |
|  - Media Action: Pause top-of-funnel ads in affected region; draft holding    |
|  - Stakeholders: Agency Account Director + Client VP Marketing                |
+-------------------------------------------------------------------------------+
|  TIER 3: BRAND EMERGENCY / EXISTENTIAL (Critical Risk)                        |
|  - Definition: National press coverage, regulatory/legal action, safety      |
|    recall, data breach, executive controversy trending on social media        |
|  - Media Action: TOTAL PAID MEDIA KILLSWITCH across all channels              |
|  - Stakeholders: Agency Founder, Client CEO, Legal Counsel, PR Lead           |
+-------------------------------------------------------------------------------+
```

## 4. The 3-Part Holding Statement Framework

Never stay silent during a Tier 3 crisis, and never give a defensive excuses speech. Issue a holding statement within 60 minutes using the **A-A-T Framework**:
1. **Acknowledge:** Acknowledge the situation directly without legal defensiveness.
2. **Action:** State what concrete steps are happening *right now* to investigate or fix it.
3. **Timeline:** Commit to a specific time when the next transparent update will be shared.

```markdown
## 2. Public Holding Statement (For Social & Press Inquiries)

> *"We are aware of [specific issue/situation] and take this matter with the utmost seriousness. Our leadership team is currently [active investigation / remediation step taking place]. The safety and trust of our customers remains our absolute priority. We are actively working to resolve this and will provide a full, transparent update today by [Time / Timezone] at [link/channel]."*

## 3. Internal Customer Support & Community Response Script
*Direct response script for Support Agents answering customer DMs and emails:*

- **Approved Customer DM Script:**
  > *"Hi [First Name], thank you for reaching out. We completely understand your concern regarding [issue]. Our executive team is currently investigating this as our top priority. Please know that [reassurance / refund policy / warranty action]. We will share an official update shortly, but if you need immediate assistance with an existing order, our team is standing by to help you here."*
- **Forbidden Phrases (DO NOT SAY):**
  - `"It's not our fault"`
  - `"You're blowing this out of proportion"`
  - `"No comment"`
  - Speculating on blame before official findings.

---

## 4. Post-Crisis Paid Media Rehabilitation Schedule
*Do not turn ads back on all at once. Follow this phased return-to-flight schedule:*

1. **Phase 1 (Day 1 - 2 Post-Resolution):** Re-enable Brand Search only with updated sitelinks addressing resolution.
2. **Phase 2 (Day 3 - 5):** Re-enable warm retargeting and retention emails with a transparent message from the founder.
3. **Phase 3 (Day 6+):** Gradually re-enable top-of-funnel cold prospecting, avoiding any creative angles that inadvertently touch on the crisis topic.
```

---

## 6. Verification Checklist

Before releasing any public crisis communication:
- [ ] Legal counsel and CEO have reviewed and approved holding statement wording.
- [ ] Every active paid media campaign has been verified paused in the respective ad account.
- [ ] Community management team is equipped with approved response scripts.
- [ ] A specific time for the next update has been declared and scheduled.
